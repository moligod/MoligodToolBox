# 客户端界面方向 · 2026-09-26

用户提供 Steam、TapTap、WeGame 截图，并确认采用顶部操作栏、左侧分类与中央工具区。参考的是导航层级、密度与中性深色，不复制商店、社交或游戏素材。

- 顶部品牌与显式搜索；按用户后续截图要求关闭系统标题栏，窗口按钮融入深色顶栏，调用 Tauri 原生最小化/最大化或还原/关闭。顶部空白区支持拖动与双击最大化；关闭沿用托盘设置。
- 左侧工具箱/设置，加全部、通用工具分类；自定义准星与自动化助手均为通用工具。三角洲行动是独立页面，只提供打开攻略站 moligod.com 的按钮。预设归各工具内部管理，准星通过输入/生成准星码使用，不设置全局预设页面或首页入口。
- 中央提供状态筛选、卡片/列表两种密度。按游戏和状态筛选可叠加搜索。
- 搜索只在按钮或 Enter 提交时执行；无远程请求、轮询或持久化新字段。
- 未接入的覆盖层和自动化明确标注，不虚构运行状态或新增工具。
- 中性深灰底色，品牌绿用于主要操作和选中提示；保留可见键盘焦点。
- 桌面最小宽度 820px；窄浏览器预览使用单列，不改变原生窗口尺寸限制。

Phosphor Core 2.1.1 仅为开发依赖。public/icons 中只带实际使用的 SVG 和许可证，无图标运行时脚本；品牌沿用项目已有资源。整个前端仍受 150 KiB 未压缩预算约束。

页面本身不滚动；顶部与左侧固定，仅中央内容区使用细深色滚动条。浏览器预览中的原生窗口按钮禁用，不模拟窗口操作成功。
