# MoligodToolBox v2.0.0

原 DF-AutomatedTool 与 FPSDiyAim 的重构整合版，面向 Windows 的本地游戏工具箱。

## 本次内容

- 自定义准星：样式、图片、颜色、尺寸、位置、显示器及快捷键设置。
- 可视化自动化助手：窗口操作、鼠标键盘、截图、图像识别、离线 OCR、条件、循环及组件库。
- 获取官方组件：在组件库中浏览、选择和导入官方动作代码；连接失败时明确提示。
- 主窗口版本更新入口：新版本红点、更新说明、确认后下载及更新签名验证。
- 工具按需启动，关闭主窗口后继续在系统托盘运行。

## 安装

下载附件中的 `MoligodToolBox_2.0.0_x64-setup.exe`，运行安装程序。支持 Windows 10/11 x64，需要 WebView2 运行时。安装包包含离线 OCR 模型及 CPU、DirectML 和 NVIDIA RTX 识别运行库；NVIDIA 专用模式需要兼容的 RTX 30 系及后续显卡与驱动。

`latest.json` 和 `.sig` 为应用内更新使用的清单和签名文件，正常安装只需下载安装包。SHA256SUMS.txt 提供附件校验值。

本次更新签名用于工具箱验证下载内容，安装包未配置 Windows Authenticode 证书。
