# 性能验收

## 自动门禁

前端 dist 全部文件未压缩合计 ≤160 KiB，由 scripts/check-budget.mjs 执行（ADR-017）。
这是当前底座的预算。新增图片、字体或第三方依赖必须说明收益与成本，不应直接上调预算绕过。
体积预算不代表进程内存；Tauri/WebView2 独立统计。

## 运行测量

仅使用 release 构建。关闭开发服务器调试影响后，记录 Windows、CPU、RAM、显示缩放、WebView2、Rust 与应用版本。
记录 exe SHA256 与配置状态。采集客户端及完整后代进程。
Working Set 汇总可能重复计算共享页；Private Bytes 汇总反映私有提交量，并不等同物理 RAM。
CPU 同时记录单核等效和整机归一化百分比。

运行中的应用可用：

```powershell
./scripts/measure-process.ps1 -RootProcessId <moligod进程ID> -Seconds 20
```

脚本输出到 artifacts，不提交个人机器完整信息。采样脚本本身不进入应用。

## 必须分开记录的场景

| 场景            | 指标                                   | 当前要求                                   |
| --------------- | -------------------------------------- | ------------------------------------------ |
| 主窗口空闲      | 全进程树 CPU/Private Bytes/Working Set | 建立基线，不宣称极致                       |
| 托盘空闲        | 同上                                   | 无截图/OCR/工具线程                        |
| 冷启动          | 从创建进程到 UI 可操作                 | 5 次，报告中位数及范围，窗口出现不等于就绪 |
| 准星开启        | 占用、游戏帧时间                       | 覆盖层接入后测量                           |
| 工具启停 100 次 | 句柄/线程/内存、停止耗时               | 真正工具接入后测量；核心单测不能替代       |
| OCR 运行与卸载  | 峰值、回收、异常退出                   | OCR 接入后测量                             |
| 退出            | 子进程是否残留                         | 每个已接入原生模块均需验证                 |

稳定机器建立重复基线后，再确定内存、CPU 和启动硬预算。当前不凭空承诺固定内存数值。
