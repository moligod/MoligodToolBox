# 原生准星 · 全新实现

用户确认：仅参考旧工具的功能用途，从头写独立 Rust 模块，不仿旧实现、不添加旧版兼容层。
本项目自身早期 v1 配置属于已有用户数据，因此保留本项目内部格式升级与备份。

## 模块边界

- core：强类型准星参数与约束，不导入 Windows/Tauri/图像库。
- crosshair/render：有限大小的 RGBA 栅格化、透明边缘裁剪、图片验证和内容寻址。
- crosshair/windows：窗口/GDI/快捷键所有权、单个按需线程、Windows 消息循环。
- src-tauri：后台命令、事件转发、图片目录与应用退出协调。
- src/crosshair-editor.ts：参数预览与交互；所有系统调用仍经 api.ts。

## 原生绘制和资源

使用 WS_EX_LAYERED / TRANSPARENT / TOOLWINDOW / NOACTIVATE，小窗口 UpdateLayeredWindow + 预乘 BGRA。不读取游戏进程，不注入，不截屏，不模拟游戏输入。
窗口尺寸随实际准星变化，不创建全屏透明 WebView。绘制完成就还原并删除 GDI bitmap/DC，窗口由 Windows 保留合成内容。
空闲阻塞在 GetMessageW，没有定时置顶或重绘循环。仅参数改变/显示器事件重绘。显示隐藏走窗口消息，不重新解码图片。
线程创建有双向确认，启动超时不会留下无人管理的消息循环。Stop 先释放窗口和热键再回复，随后 join；Tauri UI 线程不等待 join。
退出路径先设置 quitting，停止准星后 app.exit；后台请求在获取准星锁后再次检查退出状态。

## 参数与持久化

默认手动启动。十字、圆点、圆圈、自定义静态图片；参数保存为内部格式 3。已移除十字＋圆点；早期 mixed 配置读取时按十字处理，避免已保存配置无法打开。图片保存在 crosshair-images/{SHA256}.png，不能由前端提供文件路径。
开启后输入、颜色、样式、位置、居中、方向键和图片选择实时生效；使用一个在途请求和一个最新待更新值，连续操作合并而非排队积压。停止/显隐操作等待在途更新，停止时清空待更新值，无空闲轮询。
所有有效参数修改自动保存，包括准星未开启时的编辑、快捷键录入、图片选择及准星码导入；移除手动保存按钮。配置写入与实时绘制各自串行并合并最新值，窗口设置与准星设置共用配置写入队列，避免并发覆盖或因“正在保存”丢弃新改动。保存失败明确报错，保留当前草稿；无效/尚未输入完整的数字不保存。浏览器预览仅保留当前页面会话，不落盘。
输入图片 ≤8 MiB，解码限 4096×4096、分配限 80 MiB。已移除裁剪/显示的 512×512 限制，缩放按源图、滤波中间缓冲、输出、BGRA 与 DIB 的估算工作内存限制在 256 MiB 内。完全透明/损坏/不支持格式返回明确错误。相同内容去重。
缩放前先将 RGB 按 alpha 预乘，再对颜色和 alpha 一起插值，输出恢复直通 RGBA，交给原生 BGRA 转换统一合成，避免透明黑色混入边缘。无缩放时直接保留像素。
编辑器只接收最大 512 边长的缩略预览，实际覆盖层仍读取原图按用户比例显示；这个缩略图尺寸不限制导入或原生显示。托管 PNG 允许比原始压缩文件更大（≤80 MiB），避免 JPG 转 PNG 后无法重读。
准星码只包含几何/颜色/透明度/缩放等样式参数，不含图片标识、文件、显示器、偏移或快捷键。图片样式需另选图片。图片整理界面尚未提供。
纯黑色与半透明边缘按 alpha 合成，不依赖色键透明。

## 快捷键与位置

点击录入键盘键或鼠标左/右/中/两个侧键，默认 F8。支持点击切换、按住隐藏/松开恢复、按住显示/松手隐藏。使用 Raw Input 背景输入消息，只处理选中按键，不安装低级钩子、不吞输入、不轮询。系统保留的特殊按键仍受 Windows 行为约束。
隐藏仍保留监听，关闭准星则释放。键盘/鼠标类别切换时替换注册并恢复之前的注册；录入时暂停触发。按住时忽略重复按下。切到按住隐藏时立即恢复显示，切到按住显示时立即隐藏；启动按住显示也从隐藏状态开始。改键/切模式清理按住状态，松手按当前模式的固定状态恢复，不继承点击模式留下的隐藏状态。清除按住显示的快捷键会恢复可见，避免没有按键却无法显示；仅改外观不改变显隐。
坐标定义为所选显示器中心的物理像素偏移。原生线程使用 per-monitor-v2 DPI context，不改变主 UI 的 DPI 行为。越界中心收敛到屏幕内，显示器断开回退主屏。

## 验证

- 100 次创建→更新→隐藏→恢复→销毁，无遗留窗口，GDI 计数 0→0。
- 启动未改变前台窗口；命中测试 HTTRANSPARENT、扩展样式包含透明/不激活/工具窗口。
- 空闲两秒 draw_count 未增长。
- Raw Input 监听启停及键盘/鼠标类别切换通过 smoke；点击/按住状态机和键鼠映射有单测。
- 对当前 1 台连接显示器验证物理坐标偏移。
- 栅格化间距、预乘 alpha、图片透明裁剪、透明/损坏图片拒绝通过单测。

这些是原生 API 和模块测试，不能替代真实游戏、混合 DPI 多屏、显示器热插拔、实体键盘操作及每种文件格式的验收。当前不承诺独占全屏/所有游戏覆盖支持。
不包含旧版自启、提权、MOLI# 口令；它们不是此次从头实现的目标。

原生验证命令：`cargo run -p moligod-crosshair --example smoke`。
独立 Release 占用采样：编译 smoke example 后带 `--hold` 运行，会显示 45 秒并自动退出；其数字仅代表原生覆盖层，不包括 Tauri 主界面。
