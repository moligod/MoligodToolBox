# MoligodToolBox v2.0.1

- 大尺寸截图的 OCR 分块检测保留更多小字细节。离线识别继续提供 CPU、DirectML 和 NVIDIA RTX 模式。
- 自动化助手新增「定时启动」积木。空任务列表会直接打开草稿，动作注解可以在积木右侧编辑。
- 首次保存期间编辑并关窗，重新打开时仍在同一任务中恢复编辑内容。截图动作支持 Windows 扩展盘符路径。
- 正式版启动时由 Windows 请求管理员授权。安装程序和随包原生模块放在受保护的全机安装位置。

## 安装与升级

安装包为 `MoligodToolBox_2.0.1_x64-setup.exe`，适用于 Windows 10/11 x64，需要 WebView2。安装目录为 `Program Files\MoligodToolBox`。

从 v2.0.0 升级时，请退出旧版，再运行新版安装包。旧版每用户程序目录会保留，新版从全机安装位置启动。同一 Windows 账号的任务、图片和配置沿用原数据目录。

安装包的 Tauri 更新签名用于验证下载内容。`SHA256SUMS.txt` 提供附件校验值。
